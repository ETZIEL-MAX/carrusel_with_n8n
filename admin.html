Webhook n8n

Este carrusel tiene su propio webhook. n8n envía las imágenes a esta URL y se agregan al carrusel sin borrar las existentes.


        

        

          
          

        

        
La firma X-Webhook-Secret es el HMAC-SHA256 (hex) del cuerpo exacto, usando la variable WEBHOOK_SECRET del servidor. Por seguridad su valor no se muestra aquí; configura la misma en n8n (ver docs/N8N.md).


        
Copiar para n8n

        
Pega este bloque campo por campo en el nodo HTTP Request de n8n. El cuerpo ya trae las imágenes actuales de este carrusel y "mode": "append" (agregar sin borrar). Usa "replace" si quieres reemplazar todo.
