# Especificaciones técnicas del póster (V2)

Espejo de las reglas de generación del agente V2. La fuente de verdad vive en
el system prompt del workflow **Carrusel V2 — Agente**; este archivo es respaldo
y se actualiza a la par.

## Estado
Pendiente de definir por el dueño. Mientras tanto rigen las reglas base del
system prompt (foto del catálogo siempre que exista; texto en español con
ortografía correcta; nunca inventar precio; calidad máxima sin importar tiempo).

## Por definir
- Tamaños/formatos por canal (móvil, TV, redes).
- Paleta y estilo de la marca.
- Estructura fija del anuncio (título, badge, legal, etc.).
- Límites de texto por bloque.
